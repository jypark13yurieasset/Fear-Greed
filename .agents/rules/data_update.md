# 데이터 업데이트 규칙 (Data Update Rules)

사용자가 "데이터를 최신으로 업데이트 해줘" (주로 매일 아침) 라고 요청할 때 반드시 다음 규칙을 따르세요:

1. **업데이트 진행 대상 (1~4번 탭)**:
   - `index.html` (Dashboard)
   - `screener.html` (Screener)
   - `earnings.html` (Earnings)
   - `insight.html` (Insight)
   - 위 탭들의 연관 데이터(예: F&G 인덱스, 주가, 실적 데이터 등)는 기존과 같이 최신화합니다.

2. **업데이트 제외 대상 (5번 탭)**:
   - **`13f.html` (13F) 탭 및 `13f_data.json` 데이터는 절대 매일 업데이트하지 마세요.**
   - 13F 공시 정보는 분기마다 업데이트되는 정보이므로, 사용자가 **명시적으로 "13F 탭도 업데이트해 줘"라고 요청했을 때만** 예외적으로 수행해야 합니다.

3. **실행 방법 (승인 1회 원칙)**:
   - 데이터 업데이트는 외부 네트워크가 필요하므로 샌드박스 우회(BypassSandbox) 실행이 필요합니다.
   - 스크립트를 개별 실행하지 말고, 반드시 **`bash update_all.sh` 한 번으로 묶어서 실행**하여 사용자 승인을 1회만 받으세요.
   - 샌드박스 모드로 먼저 시도하지 마세요 (네트워크 차단으로 실패가 확실하며, 이전 날짜 데이터로 덮어쓰는 부작용이 있습니다).
